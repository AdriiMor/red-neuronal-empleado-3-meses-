# Sistema de Predicción de Desempeño con Red Neuronal

Proyecto desarrollado en Go que utiliza una red neuronal para predecir el desempeño laboral de un candidato durante sus primeros tres meses de trabajo, considerando características personales, académicas y profesionales.

## Características
- Implementado en Go.
- Uso de archivos CSV para almacenar datos.
- Predicción mediante red neuronal artificial.
- Estimación del desempeño laboral futuro.
- Análisis basado en experiencia, habilidades y formación académica.

## Archivos del proyecto
- main.go: Código principal.
- empleados.csv: Base de datos de entrenamiento.
- modelo.nn: Modelo entrenado.
- go.mod: Dependencias del proyecto.

## Ejecución

```bash
go run main.go
```
